# سرویس تبدیل گفتار فارسی

تبدیل گفتار سایت از مدل فارسی
[Shenava Koochik](https://huggingface.co/Reza2kn/Shenava-Koochik-v1.0-sherpa-onnx)
با مجوز Apache 2.0 استفاده می‌کند. فایل صوتی در پایگاه داده ذخیره نمی‌شود.

برای مکالمات تلفنی، فایل تا چهار ساعت به قطعه‌های یک‌دقیقه‌ای تقسیم می‌شود و متن کامل به‌همراه زمان هر قطعه برگردانده می‌شود.
مسیر `/analyze` از کتابخانه استاندارد `re` پایتون برای استخراج محافظه‌کارانه شواهد و پرکردن پیش‌نویس گزارش استفاده می‌کند؛ این مسیر مدل زبانی/هوش مصنوعی ندارد و در صورت نبود شواهد، فیلد را خالی می‌گذارد.

این سرویس می‌تواند مستقل برای فرم‌های پروژه اجرا شود. تلفن سازمانی نسخه‌ای از همین سرویس را در شبکه داخلی `docker-compose.yml` اجرا می‌کند و هر دو از volume مدل با نام ثابت استفاده می‌کنند تا مدل دوباره دریافت نشود. برای نصب مستقل قبلی:

```bash
docker compose -f docker-compose.voice.yml up -d --build
docker compose -f docker-compose.voice.yml ps
curl -fsS http://127.0.0.1:9001/health
```

بار اول مدل حدود ۴۶۰ مگابایت در volume جداگانه دریافت می‌شود. تا پایان دریافت، وضعیت
سرویس آماده نیست. مسیر API به‌صورت پیش‌فرض `http://127.0.0.1:9001`
است؛ این پیش‌فرض فقط در کانتینری که با `network_mode: host` اجرا شود در دسترس است.
در کانتینر `phone`، مقدار `PHONE_TRANSCRIPTION_FAST_URL` به سرویس داخلی
`http://voice-transcription-fast:9000` تنظیم می‌شود. اگر شبکه‌بندی سفارشی است،
این متغیرها را متناسب با شبکه داخلی سرور تنظیم کنید.
