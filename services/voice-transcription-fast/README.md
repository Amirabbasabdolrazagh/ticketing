# آزمایش مدل دوم تبدیل گفتار

«مدل ۱» همان سرویس Whisper فعلی است. «مدل ۲» از مدل فارسی
[Shenava Koochik](https://huggingface.co/Reza2kn/Shenava-Koochik-v1.0-sherpa-onnx)
با مجوز Apache 2.0 استفاده می‌کند. هیچ‌کدام فایل صوتی را در پایگاه داده ذخیره نمی‌کنند.

این سرویس آزمایشی مستقل از `docker-compose.yml` اصلی اجرا می‌شود:

```bash
docker compose -f docker-compose.voice-trial.yml up -d --build
docker compose -f docker-compose.voice-trial.yml ps
curl -fsS http://127.0.0.1:9001/health
```

بار اول مدل حدود ۴۶۰ مگابایت در volume جداگانه دریافت می‌شود. تا پایان دریافت، وضعیت
سرویس آماده نیست. مسیر API مدل دوم به‌صورت پیش‌فرض `http://127.0.0.1:9001`
است؛ این پیش‌فرض در سروری کار می‌کند که کانتینر اصلی سایت با `network_mode: host`
اجرا می‌شود. در شبکه‌بندی دیگر، مقدار `VOICE_TRANSCRIPTION_FAST_URL` را برای
کانتینر سایت تنظیم کنید.

برای مقایسه، یک جملهٔ یکسان را با هر دو دکمهٔ کنار فیلد ضبط کنید. زمان و متن
هر مدل در بخش «مقایسهٔ خروجی و زمان مدل‌ها» نمایش داده می‌شود. انتخاب مدل دوم
تنظیمات یا داده‌های مدل اول را تغییر نمی‌دهد.
